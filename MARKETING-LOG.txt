===============================================================================
1. POSITIONIERUNG & MARKTKONTEXT
===============================================================================

SQLiteViewer schließt die Lücke zwischen überladenen, schwergewichtigen Datenbank-
IDEs (wie DBeaver mit Java-VM-Overhead oder DB Browser for SQLite mit C++/Qt-
Installationszwang) und der bloßen SQLite-Kommandozeile.

Ziel: Ein leichtgewichtiger, portabler, 100% offline arbeitender SQLite-Viewer mit
Tkinter-Oberfläche, der direkt aus Python gestartet oder als unprivilegierte
Windows-App aus dem Microsoft Store bezogen werden kann.

Kern-Mehrwerte:
1. Zero Network Egress (INV-LOCAL-01): Garantiert keine Cloud-Verbindungen, keine Telemetrie.
2. Unprivilegierte Ausführung (INV-LOCAL-02): Strikter RunAsInvoker-Betrieb ohne Adminrechte.
3. Zero External Dependencies (INV-LOCAL-03): Python Standardbibliothek (sqlite3) + Tkinter.
4. Kontextabhängiger Export (INV-LOCAL-05): CSV sowie strukturiertes JSON (sqliteviewer-export-v1).
5. Offline Web-Companion (INV-LOCAL-06): Lokale HTML/JS-Inspektion im Browser ohne Upload.
6. Microsoft Store Integration (INV-LOCAL-07): Standard-AppX mit Dateiverknüpfungen (.db, .sqlite, .sqlite3).
