## Description

SQLite Viewer Pro is a fast, portable local SQLite database browser. It opens `.db`, `.sqlite`, and `.sqlite3` files instantly in read-only mode and lets you browse tables, inspect schemas, execute SQL queries, and export results without cloud connectivity or external runtime dependencies.

KEY FEATURES:
- Table Browser: Automatically lists all tables and views and displays rows in a sortable grid
- Schema View: Inspect `CREATE TABLE` definitions with clear syntax highlighting
- SQL Editor: Write and execute custom SQL queries with debounced highlighting and dedicated result view (`F9`)
- Full-Text Search: Real-time filtering across all visible columns (`Ctrl+F`)
- CSV Export: Export any table or query result safely to a formula-hardened CSV file (`Ctrl+E`)
- JSON Export: Export the active view as `sqliteviewer-export-v1.json` for offline companion workflows (`Ctrl+Shift+E`)
- Accessible Keyboard Navigation: `Ctrl+O`, `Ctrl+W`, `Ctrl+F`, `Ctrl+E`, `F1`, `Shift+F1`, `F5`, `F9`, `Ctrl+1..3`
- Read-only Safety: Protects source SQLite files and WAL/SHM sidecars against accidental modification or overwrite

WHO IT IS FOR:
Developers, data analysts, researchers, and system administrators who want to inspect and export local SQLite files immediately without the overhead of heavyweight database suites or external runtime frameworks.
