# SQLite Viewer Pro — Store Listing (日本語 / ja-JP)

## アプリ名
SQLite Viewer Pro

## 簡単な説明（最大 100 文字）
軽量ローカル SQLite ブラウザ：データベースの閲覧・検索・SQL実行・出力を即座に実行。

## 詳細な説明

SQLite Viewer Pro は、高速でポータブルなローカル SQLite データベースビューアです。`.db`、`.sqlite`、`.sqlite3` ファイルを読み取り専用モードで瞬時に開き、クラウド接続や外部ランタイムへの依存なしに、テーブル閲覧、スキーマ確認、SQL クエリ実行、データ出力を安全に行えます。

主な機能：
- テーブルブラウザ：すべてのテーブルとビューを自動検出し、ソート可能なグリッドで表示
- スキーマインスペクタ：構文ハイライト付きで `CREATE TABLE` 定義をわかりやすく表示
- SQL エディタ：独自の SQL クエリを作成・実行し、専用ペインに結果を表示（`F9`）
- 全文検索：表示中のすべての列を対象にしたリアルタイムフィルタリング（`Ctrl+F`）
- CSV エクスポート：テーブルやクエリ結果を安全な標準 CSV 形式で出力（`Ctrl+E`）
- JSON エクスポート：オフライン確認用の `sqliteviewer-export-v1.json` 形式で出力可能（`Ctrl+Shift+E`）
- キーボード操作：`Ctrl+O`、`Ctrl+W`、`Ctrl+F`、`Ctrl+E`、`F1`、`Shift+F1`、`F5`、`F9`、`Ctrl+1..3` に対応
- 読み取り専用保護：元データベースおよび WAL/SHM 関連ファイルへの誤書き込みを防止

対象ユーザー：
重厚なデータベース管理スイートや外部ランタイム環境を導入せずに、ローカルの SQLite データベースを素早く安全に確認・検証・エクスポートしたい開発者、データアナリスト、研究者、IT サポート担当者。
