# SQLite Viewer Pro — Store Listing (简体中文 / zh-CN)

## 应用名称
SQLite Viewer Pro

## 简短描述（最多 100 个字符）
轻量级本地 SQLite 数据库浏览器：快速打开、检索、查询并安全导出数据。

## 详细描述

SQLite Viewer Pro 是一款快速、便携的本地 SQLite 数据库浏览器。它能够以只读安全模式即时打开 `.db`、`.sqlite` 和 `.sqlite3` 文件，让您在零网络连接且无外部运行时依赖的前提下，轻松浏览数据表、检查结构、运行 SQL 查询并导出结果。

核心功能：
- 数据表浏览器：自动列出所有表与视图，并在可排序网格中清晰展示记录
- 数据结构查看：通过语法高亮直观检查 `CREATE TABLE` 结构定义
- SQL 编辑器：编写并执行自定义 SQL 查询，提供独立结果视图（`F9`）
- 全文检索：针对当前可见的所有数据列提供实时过滤搜索（`Ctrl+F`）
- CSV 导出：将任意数据表或 SQL 查询结果安全导出为标准 CSV 文件（`Ctrl+E`）
- JSON 导出：支持导出 `sqliteviewer-export-v1.json`，便于离线伴侣审阅（`Ctrl+Shift+E`）
- 无障碍快捷键：支持 `Ctrl+O`、`Ctrl+W`、`Ctrl+F`、`Ctrl+E`、`F1`、`Shift+F1`、`F5`、`F9`、`Ctrl+1..3`
- 严格只读保护：防止意外修改或覆盖源数据库及 WAL/SHM 附属文件

适用人群：
需要快速查看、排查与安全导出本地 SQLite 数据库的软件开发者、数据分析师、科研人员与系统运维工程师，无需安装臃肿的大型数据库套件或外部运行时框架。
