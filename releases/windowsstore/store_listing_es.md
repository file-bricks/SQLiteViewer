## Descripción corta (máx. 100 caracteres)
Navegador SQLite ligero: abra, busque, consulte y exporte bases de datos localmente.

## Descripción

SQLite Viewer Pro es un navegador de bases de datos SQLite rápido, local y portátil. Abre archivos `.db`, `.sqlite` y `.sqlite3` al instante en modo de solo lectura y permite explorar tablas, revisar esquemas, ejecutar consultas SQL y exportar datos sin conexión a la nube ni dependencias externas.

FUNCIONALIDADES PRINCIPALES:
- Explorador de tablas: enumera automáticamente tablas y vistas en una cuadrícula ordenable
- Vista de esquema: inspecciona definiciones `CREATE TABLE` con resaltado de sintaxis
- Editor SQL: redacta y ejecuta consultas SQL personalizadas con vista de resultados dedicada (`F9`)
- Búsqueda en tiempo real: filtrado instantáneo en todas las columnas visibles (`Ctrl+F`)
- Exportación a CSV: guarda tablas o resultados de consultas en archivos CSV seguros (`Ctrl+E`)
- Exportación a JSON: exporta la vista activa como `sqliteviewer-export-v1.json` para revisión local (`Ctrl+Shift+E`)
- Atajos accesibles: `Ctrl+O`, `Ctrl+W`, `Ctrl+F`, `Ctrl+E`, `F1`, `Shift+F1`, `F5`, `F9`, `Ctrl+1..3`
- Protección de solo lectura: evita modificaciones accidentales sobre la base de datos de origen

PARA QUIÉN:
Desarrolladores, analistas de datos, investigadores y administradores de sistemas que necesitan inspeccionar bases de datos SQLite locales con rapidez y total privacidad, sin suites pesadas ni entornos externos.
